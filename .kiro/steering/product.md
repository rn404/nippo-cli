# Product Overview

`sava` (nippo-cli) はターミナルを離れずに使う独り言メモ／日報補助ツール。
エンジニアは作業時間の大半をコンソールで過ごすため、他ツールへのスイッチ
コストを払わずに「作業ログ」と「ちょっとした思考」を残せることを狙う。

## Core Capabilities

- **メモ / TODO の記録**: `add` で一言メモ、`todo` でタスクを追加し、
  `start` / `end` で作業の開始・終了を記録する。
- **タグ付けと絞り込み**: 追加時または事後 (`tag`) にタグを付け、
  `list -t` で AND/OR 条件による絞り込みができる。
- **経過時間の把握**: `diff` で任意の2項目間の経過時間を算出し、
  工数管理・振り返りに使う。
- **日次ログの閲覧・整理**: `list` で当日/指定日/全期間/サマリを表示し、
  `clear` で保存期間（30日）を過ぎたログを削除する。
- **壊れても再構築できるインデックス**: タグ検索用の逆引きキャッシュ
  (`~/.log/sava/index.json`) は全ログから再生成可能な補助データ。

## Target Use Cases

- 作業中に思いついたことをコマンド一発でメモしたい。
- 日報を書くために、1日の作業内容・タスクの開始終了を後から拾いたい。
- タグや経過時間から、特定作業にかかった時間をざっくり把握したい。

## Value Proposition

- ログは `~/.log/sava/<yyyy-MM-dd>.json` に1日1ファイルで保存され、
  フォーマットは `testdata/log-format/` に仕様サンプルとして固定されている
  ため、他ツールからの読み取りや将来の互換性検証がしやすい。
- Go 製の単一バイナリで配布され (`go install` またはビルド済みバイナリ)、
  依存を増やさずに素早く使い始められる。
